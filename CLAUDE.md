## Project
A todo application where you can tag and prioritize entries, add links to tickets and set dependencies to other entries and/or anything in a custom text. The application is built to make it easier to keep track of what needs to be done next.

## Tech stack
- C#
- Blazor
- SQL Express

## Architecture
- Functions should only have one responsibility
- Constants should be kept in a constants file
- All major functionality should have tests

## Rules
- Don't add dependencies without asking
- Don't comment code that is already explained by function and/or variable names and by reading what it does
- Never commit directly to main, work in feature branches
